# VRM 模型目录（运行时资产）

`ui_character` 卡片按**文件名**解析到此目录（如 `model: "cinnamon.vrm"` → `/vrm/cinnamon.vrm`）。
`.vrma` 动作文件同样放这里。

- 本目录的文件会随构建拷贝进 `dist/client`（生产部署生效）；**大文件不提交 git**，放本地即可
- 目录为空卡片也能用：默认加载 three-vrm 官方示例模型（需要外网）
- 模型来源建议：VRoid Hub、社团分发的免费模型等——注意各模型的使用许可
- 也可以在卡片里直接给 https 直链（如官方示例模型），无需放置文件

## 快速自检

放一个 `demo.vrm` 后，让 AI「用 demo.vrm 打个招呼」即可看到 3D 卡片；
若显示「3D 模型加载失败」，检查文件名拼写与 dev server / 生产构建的静态目录是否已包含该文件。
